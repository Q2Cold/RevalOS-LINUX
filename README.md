# Reval OS

Reval OS — экспериментальный Linux-дистрибутив на базе Linux From Scratch.

## Reval OS 0.2 Universal Preview

- Ядро: Linux 7.1.8-reval-universal
- Загрузка: BIOS и UEFI
- Рабочий стол: Openbox и Tint2
- Установка программ: Nix и Reval Software
- Языки: русский, английский и казахский
- Live-режим и экспериментальное сохранение данных
