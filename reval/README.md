# Исходники компонентов Reval OS

overlay/ — файлы Reval с путями относительно корня системы.
boot/ — сценарий initramfs и меню загрузки Live ISO.
kernel/ — конфигурация ядра.

Это исходники компонентов и настройки, а не полный рецепт сборки ОС.
База LFS/BLFS, зависимости, Nix-пакеты и прошивки требуют отдельного описания.
Путь home/myos сохранён для совместимости с текущей версией.
