# Индикатор раскладки

Сборка из корня репозитория:

    ./scripts/build-layout.sh

Нужны компилятор C, заголовки и библиотека X11.
Результат: build/reval-layout.

Запускать внутри графического сеанса Xorg.
Индикатор рассчитан на порядок раскладок us,ru,kz.
Он показывает активную группу, но не переключает раскладку.

Готовый файл в overlay относится к прежней сборке Reval.
Для обновления следует собирать программу в целевой системе
или в совместимом окружении сборки.
